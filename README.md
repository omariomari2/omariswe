# Personal portfolio

Source for Bright Omari Owusu's portfolio at [omari.is-a.dev](https://omari.is-a.dev/).
Built with HTML, CSS, JavaScript, and exported website assets.

## Preview locally

Run this command from the repository directory with Python 3:

```sh
python -m http.server 8000
```

Open `http://localhost:8000`.
The repository includes the homepage, an about page, project pages, and a `CNAME` file for the custom domain.
External assets can require network access. Keep existing asset and template attribution when reusing the source.
